Como instalar

🚜 Mods (GPS RBT, Ajudas…)

  1. Baixe o .zip do mod. Não extraia.
  2. Copie o .zip para a pasta Documentos\My Games\FarmingSimulator2025\mods.
  3. Se já tinha uma versão antiga, substitua (o nome é o mesmo).
  4. Servidor dedicado (alugado ou próprio): o admin põe o mesmo .zip na pasta mods do servidor, pelo painel ou FTP. Todos precisam da mesma versão.

📱 Tablet RBT

  1. Baixe o Tablet RBT para PC, extraia o .zip numa pasta (ex.: área de trabalho).
  2. Abra Tablet RBT.bat. Na 1ª vez o Windows pergunta se permite alterações: clique Sim. Deixe a janela aberta.
  3. No Android, instale o APK (ou abra o navegador) no mesmo Wi-Fi do PC e digite o endereço que a janela mostra.
  4. Na 1ª vez, digite o código de 4 números da janela. Entre numa máquina no jogo.

Dúvidas

Por que preciso pedir acesso?

Os mods RBT são feitos para o pessoal do servidor. Você entra com o Google uma vez, pede o acesso e, depois de aprovado, baixa sempre que quiser, em qualquer aparelho com a mesma conta.

O aplicativo do tablet substitui o programa do PC?

Não. O programa do PC (Tablet RBT.bat) lê o jogo e manda para o tablet. O app só mostra a tela e mantém ela acesa. Os dois precisam estar no mesmo Wi-Fi.

Como instalar o APK no Android?

Baixe o APK no próprio tablet, toque nele e, se o Android pedir, permita “instalar apps desta fonte” para o navegador. Depois é só abrir o Tablet RBT. Android 6.0 ou mais novo.

O mod não aparece no jogo.

Confira se o .zip está direto dentro da pasta mods (não dentro de outra pasta) e se não foi extraído. No servidor, a versão do mod tem que ser a mesma de todos.

Cada mod tem ajuda dentro do jogo?

Sim. Com o Ajudas RBT ativo, aperte ESC e abra a aba AJUDAS: tem a explicação de cada mod RBT que está ligado.
